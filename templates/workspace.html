Arsitektur AI

Bagaimana Teknologi AI Shroomy Bekerja?

Shroomy mengimplementasikan pipeline komputasi modern yang memadukan deep learning MobileNetV2 sebagai Feature Extractor (1.280 dimensi) dan Classifier SVM RBF untuk identifikasi 39 spesies serta edukasi mikologi ilmiah.

Tahap 01

Akuisisi Citra Jamur

Pengambilan gambar secara langsung melalui kamera realtime atau unggah file foto spesimen (JPG, PNG, WEBP) dari galeri perangkat Anda.

Input: Realtime Camera / Upload
Tahap 02

Standarisasi & Normalisasi

Citra distandarisasi ke resolusi 224×224 px dalam format RGB, lalu dinormalisasi menggunakan bobot statistik standar ImageNet.

Format: 224×224 px RGB · ImageNet Norm
Tahap 03

Ekstraksi Fitur MobileNetV2

Backbone convolutional MobileNetV2 pretrained ImageNet mengekstrak representasi visual berdimensi 1.280 (pola permukaan, bentuk tudung, dan struktur biologis).

Feature Vector: 1.280 Dimensi
Tahap 04

Klasifikasi Dual SVM RBF

Vektor 1.280 dimensi diproses oleh Classifier SVM RBF Multikelas (39 Spesies) untuk identifikasi taksonomi dan SVM Biner untuk klasifikasi referensi pendukung.

Classifier: SVM RBF (39 Spesies & Biner)
Tahap 05

Edukasi & Basis Pengetahuan

Hasil identifikasi dipetakan ke basis pengetahuan mikologi terverifikasi untuk menampilkan profil morfologi, habitat, fakta edukatif, dan status referensi ilmiah.

Knowledge Base: 39 Spesies Terverifikasi

Transparansi Arsitektur: MobileNetV2 Feature Extractor + SVM Classifier

Penjelasan ilmiah mengenai pipeline Machine Learning pada platform Shroomy

Prinsip Keterbukaan Sains

Model Aktif: MobileNetV2 (1.280 Dimensi) + Dual Classifier SVM RBF

Shroomy menggunakan MobileNetV2 sebagai feature extractor untuk menghasilkan vektor representasi visual 1.280 dimensi, yang kemudian diklasifikasikan oleh model SVM RBF Multikelas (39 Spesies) dan SVM RBF Biner (2 Kelas).

Pemeriksaan Konsistensi & Ambang Keyakinan 50%

Sistem membandingkan hasil identifikasi spesies dengan hasil klasifikasi referensi biner serta menerapkan ambang keyakinan visual 50% agar hasil yang belum meyakinkan tidak disajikan sebagai kepastian.
